## 人设预设（PersonaPresets）

用户诉求：多份预设人设，同一时间只能勾选一份。

**关键设计决定**：一份预设存**两个来源**，不只存话术三件套。
- `personaJson`（设置页那段 JSON：身份/语气/禁忌词）
- `override`（`user_persona.json`：情况/样例/准则）

只换后者 = "怎么说话"变了但"我是谁"没变，而多号之间最容易露馅的正是身份。
切换 = 两份一起写回，`PersonaLoader` 一行没改。

- 档案柜：`filesDir/persona_presets.json`，`{active, presets:[{id,name,body}]}`
- 唯一性靠 `active` 字段，不靠界面单选框（界面只是投影）
- **存任意一页都自动快照**：`PersonaActivity.persist()` 和 `SettingsActivity.save()` 都调
  `snapshotActive()` —— 漏了会"切走再切回把改动还原"
- 界面用 `● / ○` 而不是 `RadioButton`：RadioButton 点击会自己翻转选中态，
  和"点当前那份什么也不发生"冲突
- 最后一份不能删；删掉生效那份自动回落

**验证**：`tools/verify_presets.py` —— 源码不变量核对 + Python 复刻规则跑边界。
过程中抓到我自己的一个**测试断言**写错（`create` 之前会先快照，所以第一份内容已经变了），
不是代码错。这类"复刻测试"要先想清被复刻的副作用的顺序。
