先做抖音是对的，
但它不是最省事的那条

在评论回复这个动作上，抖音确实是四个平台里唯一有完整官方能力的： 能拉列表、能回复、能置顶。但它同时也是门槛最高的—— 需要企业主体、应用转正、互动管理权限三道关。 这份手册是给"照着做"用的，不是给"看看"用的。

先说清楚「最全」的准确含义

能力最全 ≠ 最好上手。抖音有官方接口，意味着稳定、有文档、能精确回复到某条评论下； 但也意味着你要先过一个审核链。QQ 的 OneBot 零门槛但非官方，小红书干脆没有接口。

所以真正的问题不是「抖音是不是最全」，而是你的资质到哪一步了。 资质没下来之前，代码可以照写、用假数据跑通全链路，等权限批了直接换 real transport。

01

令牌生命周期：第 16 天会发生什么

这是最容易被忽略、后果最严重的一件事。access_token 只有 15 天, 不是很多文档里说的 2 小时（那是 client_token，用途不同）。 如果你没做自动刷新，第 16 天开始所有请求都会失败，而且表现是「回复莫名其妙不发了」。

不做任何处理：第 16 天断。只做刷新不做续期：第 45 天断。 有续期权限：第 195 天断，之后必须让用户重新授权一次。 这个数字要提前知道，否则到了那天你会以为是自己代码坏了。

代码里的处理是：`ensure_token()` 在每次请求前检查，留 1 小时余量 （本地算着没过期、请求路上过期，同样会失败）；刷新结果立刻落盘， 进程重启不用重新授权。

# 令牌落盘：token.json，已在 .gitignore 里排除 { "access_token": "act.xxx", "refresh_token": "rft.xxx", "open_id": "xxx", "expires_at": 1794000000 }
这个文件绝对不能提交。泄露 access_token 等于把账号接口交出去， 泄露 refresh_token 更严重——它能把令牌续到 195 天。 仓库里的 .gitignore 已经排除了它，但如果你手动复制过，记得检查。

03

错误码：哪些能自愈，哪些必须找人

抖音的错误码分两类，混在一起处理会导致两种坏结果： 能自愈的当成致命错误（白白停摆），或者必须人工的当成可重试（死循环打接口）。

错误码含义处理说明
0 成功 正常 —
10008 / 2190008 access_token 过期 自动刷新 两个码平台都在用，必须都判。刷新后重试一次，只重试一次
10010 refresh_token 过期 需重新授权 刷新也救不回来。代码里会触发 on_reauth_needed 回调，通知你去重新扫码
其他业务码 权限不足 / 参数错误 / 频控 记录并跳过 看返回的 description 定位。不要盲目重试，先读错误信息

代码里 DouyinError.recoverable 这个属性就是干这个用的： True 表示刷新能救，False 表示必须人工介入。 上层据此决定是重试还是告警，不用在每个调用点重复判断错误码。

04

除了令牌，还有三件必须做

去重

同一条评论会被反复拉到——除非你记住哪些已经处理过。 不做去重的后果是同一个用户收到三条一样的回复，这比不回复更像机器人。 代码里用 comment_id 落盘去重，默认保留 30 天。

限流

接口有 QPS 限制。默认最小间隔 1 秒，看起来保守，但评论拉取本来就是低频操作—— 真正需要控制的是「别在几秒内连打十几次」。被打频控的代价是整个账号的接口调用受影响。

翻页上限

max_pages 默认 3。如果不限制，第一次接入时会把历史评论全部拉下来， 然后一次性生成几百条草稿——你的待确认队列会被冲垮，而且很容易触发频控。

# 参数都在构造函数里，按实际情况调 adapter = DouyinAdapter( client, item_ids=["7300000000000000000"], seen=SeenStore("douyin_seen.jsonl"), # 去重账本 page_size=20, # 每页条数 max_pages=3, # 每轮最多翻几页 ) client = DouyinClient( client_key=..., client_secret=..., open_id=..., token_store=TokenStore("token.json"), min_interval=1.0, # 最小请求间隔（秒） )

三句话

  1. 抖音是「官方能力最全」，不是「最省事」。 评论列表、回复、置顶都有，但要走完企业主体、应用转正、互动管理三道审核。 资质没下来也能开发——用假 transport 跑通全链路，批了直接换真接口。
  2. 令牌是这条链路上最容易断的地方。 access_token 15 天、refresh_token 30 天、有续期权最长 195 天。 不做刷新第 16 天断，只刷新不续期第 45 天断。这个日期要提前知道。
  3. 去重、限流、翻页上限看着是小事，不做就跑不下去。 它们防的不是平台，是你自己：重复回复、被频控、队列被历史评论冲垮。
